Private Lybreri - HTML/CSS/JS

This version keeps the approved React-matching visual design and applies the latest requested changes:

1. Wishlist empty state no longer uses a separate glass card; the message is centered in the main content area.
2. Wishlist hearts use a red selected state and remain clickable.
3. Settings was removed from the main navigation list and placed at the bottom of the sidebar as a clickable footer item.
4. The topbar date is more visible.
5. The greeting changes automatically from the browser/system local time: Good morning, Good afternoon, Good evening, or Good night.
6. The Currently Reading decoration is moved to the far-right side, with the Genre/Started/Est. Finish/Location area given more room.

Open index.html in a modern browser. IndexedDB/localStorage behavior remains local to the browser.
